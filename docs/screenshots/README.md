# Screenshots

Drop three PNGs in this directory, then uncomment the screenshot table in the
root [README.md](../../README.md) — the markup is already there, commented out.

Expected filenames:

| File | Screen |
| --- | --- |
| `deck-list.png` | Deck list |
| `study.png` | Study screen, back side showing all four answer buttons |
| `browser.png` | Card browser |

How to capture:

1. Run the app in the iOS Simulator (iPhone 15 Pro or newer).
2. Import a deck so the screens are not empty — a screenshot of an empty deck
   list is worse than no screenshot.
3. `⌘S` in the Simulator saves a PNG to the Desktop.
4. Rename to the filenames above and put them here.
